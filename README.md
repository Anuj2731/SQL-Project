# SQL-Project
This project involves analyzing the orders dataset to gain insights into sales trends, customer behavior, and other key performance metrics. The project includes data cleaning and exploratory data analysis (EDA).

**Features**

  1. Data Cleaning:
  
      Removed duplicate records
  
      Handled missing values
  
      Standardized data types (e.g., dates)
  
  2. Exploratory Data Analysis (EDA):
  
      Summary statistics of numerical columns
      
      Distribution analysis of sales
      
      Regional sales trends
  
      Categorical Sales
     
   
**Repository Contents**

  orders.csv: Raw dataset used for analysis
  
  Data_Project.ipynb: Jupyter Notebook containing Python code for data cleaning and EDA
  
  orders_analysis.sql: SQL queries used for data exploration (if applicable)
  
  cleaned_orders.csv: Cleaned dataset ready for Power BI visualization
  

**Results**

  Gained insights into the most profitable regions and categories
  
  Identified trends in sales, shipping times, and correlations between variables
  

**Future Scope**

  Expand the dataset with more time-series features
  
  Integrate predictive analytics for future sales forecasting
  
  Automate the pipeline for real-time data updates
